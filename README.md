# Odin Todo

Simple todo app.

# Goal

Practice webpack, ES Modules, classes, and OOP.

## Project brief

See [project page](https://www.theodinproject.com/lessons/node-path-javascript-todo-list) on The Odin Project.

## Stack

- Vanilla JS + ES modules
- webpack + webpack-dev-server
- Node / npm

## Quick start

- Install: `npm install`
- Start dev server: `npm start`
